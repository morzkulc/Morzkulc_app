# kurs.morzkulc.pl

Statyczna strona kursu. Firebase Hosting, projekt `morzkulc-e9df7`, site `morzkulc-kurs`, target `kurs`.

- Deploy: `firebase deploy --only hosting:kurs --project morzkulc-e9df7`
- Aplikacja to target `app`: `--only hosting:app`. Samo `--only hosting` wdraża oba.
- Adres techniczny: https://morzkulc-kurs.web.app
- DNS morzkulc.pl: Cloudflare, rekordy w trybie „DNS only” (jak `app.morzkulc.pl`).
