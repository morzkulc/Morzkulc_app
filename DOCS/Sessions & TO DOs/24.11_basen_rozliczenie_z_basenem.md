# 24.11 — Basen: rozliczenie terminów z basenem — WDROŻONE

Prośba obsługi basenu: pamiętać, które odbyte terminy są już rozliczone (faktura od właściciela basenu albo gotówka), żeby nie policzyć ich przy kolejnej prośbie o fakturę.

## Decyzje (24.11)
| # | Decyzja |
|---|---|
| 1 | Oznacza **tylko obsługa basenu** (`resolveBasenAdminGrant`: `basen_admin_mail` z SETUP + skarbnik). Zarząd/KR bez nadania — podgląd |
| 2 | Tylko znacznik: **faktura wystawiona** albo **zapłacono gotówką (data)**. Bez kwot, bez VAT w systemie |
| 3 | Gotówkę osoba prowadząca basen rozlicza sama — system nie liczy zwrotów |
| 4 | Terminy kursowe — tak samo jak reszta |
| 5 | Bez numerów faktur |
| 6 | Wszystkie odbyte startują jako „do rozliczenia”; stan ustawia obsługa basenu |
