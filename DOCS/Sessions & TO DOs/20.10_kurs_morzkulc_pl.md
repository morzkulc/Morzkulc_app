# 20.10: strona kurs.morzkulc.pl — konfiguracja

## Zrobione

| Co | Stan |
|---|---|
| Site Hosting `morzkulc-kurs` w projekcie `morzkulc-e9df7` | utworzony, https://morzkulc-kurs.web.app → 200 |
| `firebase.json`: `hosting` → tablica 2 targetów: `app` (bez zmian w konfiguracji), `kurs` (`site_kurs/`, cleanUrls) | gotowe |
| `.firebaserc`: targety prod (`app`, `kurs`) i dev (`app`) | gotowe |
| `site_kurs/index.html`: zaślepka „w przygotowaniu”, `noindex` | wdrożona |

**Zmiana w deployu:**
- aplikacja: `--only hosting:app`;
- kurs: `--only hosting:kurs`;
- samo `--only hosting` wdraża oba.

## Do zrobienia przez użytkownika: domena

1. Firebase Console → Hosting → site **morzkulc-kurs** → „Add custom domain” → `kurs.morzkulc.pl`.
2. Rekordy podane przez Firebase dodać w Cloudflare (DNS strefy morzkulc.pl):
   - tryb **DNS only** (szara chmurka), tak jak `app.morzkulc.pl`;
   - z pomarańczową chmurką certyfikat Firebase się nie wystawi.
3. Poczekać na status „Connected” (certyfikat SSL: do kilku godzin).

## Później

- Treść strony do ustalenia.
- Jeśli strona ma pokazywać dane na żywo (terminy, cena), trzeba:
  - dopisać `https://kurs.morzkulc.pl` i `https://morzkulc-kurs.web.app` do `PUBLIC_SITE_ORIGINS` (`getPublicSiteHandler.ts`);
  - rozszerzyć whitelistę pól;
  - wdrożyć `publicSiteInfo`.
- Usunąć `noindex` przy publikacji.
