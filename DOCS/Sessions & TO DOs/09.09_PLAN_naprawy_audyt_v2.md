# PLAN naprawy — audyt niezależny v2 (09.09.2026)

Źródło: `09.09_audyt_niezalezny_v2.md` (N1–N20 + § 5). Stan kodu: `5f2ac0c`.

**Zasady obowiązujące przy realizacji**
- Commity robi wyłącznie użytkownik. Deploy: `firebase use prod` + `firebase deploy --only functions[:nazwa]` / `--only hosting` / `--only firestore:indexes`.
- Zmiana w `service/tasks/*.ts` = redeploy `onServiceJobCreated` **i** `appsScriptSync` (i schedulera, który dany task woła).
- Nowa funkcja HTTP = wpis w `firebase.json` `hosting.rewrites`; invoker przełącza użytkownik (tylko zgłosić). Nowy scheduler/trigger = bez zmian invokera.
- Nowe pole w `ServiceConfig` musi mieć hardkodowany fallback.
- Martwy kod i osierocone dane usuwane w tym samym etapie.
- Każdy etap: `npm --prefix functions run lint && npm --prefix functions run build && npm --prefix functions test` zielone → deploy → weryfikacja na prod → wpis w tym pliku (kolumna „Stan").
