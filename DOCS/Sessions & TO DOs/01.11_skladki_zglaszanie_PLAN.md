# Zgłaszanie wpłat składek i wpisowego w aplikacji — plan (01.11 / 02.11.2026)

## Zasada
Jedynym źródłem daty „Składki opłacone do” jest kolumna **„Składki”** w arkuszu członków.
- Aplikacja wpisuje datę **do arkusza**, a dopiero po udanym zapisie do bazy (ta sama wartość).
- Ręczne wpisy skarbnika w arkuszu działają dalej; sync 04:20 i z menu je przenosi.

## Zrobione 02.11 (WDROŻONE funkcje)
| Co | Stan |
|---|---|
| SETUP ↔ arkusz | okresy 10-01–02-28 i 03-01–09-30; arkusz poprawiony, zgodny |
| Walidacja syncu | data = `semestr_1_stop` / `semestr_2_stop`, odrzuca nieistniejące daty (np. 2027-02-29) |
| Cofnięcie / usunięcie daty | sync STOP bez zapisów → pytanie TAK/NIE w arkuszu (tokeny `memberId|z|na`); nocny sync czeka na człowieka. **Apps Script niewgrany (clasp login)** |
| Karnet basenowy | bez sztywnego 31.03; tylko `basen_koniec_sezonu` (brak/miniony → karnet niedostępny) |

## Decyzje (02.11)
| # | Decyzja |
|---|---|
| P1 | Składkę płaci członek / Zarząd / KR. Kandydat płaci **wpisowe = 2 × składka**; przy basenie itp. liczone jak składka |
| P2 | Pierwsza wpłata (brak daty) → koniec **najbliższego** semestru + (n−1). Kontynuacja → od obecnego „opłacone do”: **najpierw zaległe semestry**, potem na plus |
| P3 | Wiele semestrów naraz, bez limitu |
| P4 | Potwierdza **skarbnik** (funkcja `skarbnik`) |
| P5 | Wpisowe tym samym mechanizmem; rola kandydat → zgłoszenie = wpisowe, zawsze 2 semestry |
| P6 | Bez maila przy zgłoszeniu; mail do skarbnika, gdy zgłoszenie czeka > 3 dni |
| P7 | Kwota = `składka` z SETUP × n, bez korekty |
| R1 | Bez automatu. Skarbnik: lista osób z zaległymi składkami + „Wyślij przypomnienie” (pojedynczo i zbiorczo, ptaszki) |
| R4 | Bez zestawienia — wystarcza raport składek / prawa głosu |
| R5 | Członek może włączyć powiadomienia o składkach (jak o imprezach) |
| D2 | 29.02 to koniec semestru w roku przestępnym |

## Nowa data po wpłacie
- `brak daty` → `koniec semestru zawierającego dziś` + (n−1) kolejnych.
- `jest data` → od niej + n kolejnych końców semestrów (zaległość schodzi pierwsza).
- Rok przestępny: koniec lutego = ostatni dzień lutego.

## Elementy techniczne
| Element | Co |
|---|---|
| `dues_orders` | uid, memberId, rodzaj (składka/wpisowe), n, kwota, tytuł, status, decyzja |
| API (appApi) | `GET/POST /api/dues` (stan, zgłoś, anuluj), `GET/POST /api/admin/dues` (lista, potwierdź, odrzuć, przypomnij) |
| Joby | `dues.notifyOrder` (dane przelewu do członka), `dues.writeBack` (arkusz → baza → mail), `dues.daily` (alert skarbnika > N dni + przypomnienia dla chętnych), `dues.sendReminder` |
| UI | kafelek „Składki” u członka; panel skarbnika: zgłoszenia + zaległości z przypomnieniami |
| Testy | wyliczanie daty (pierwsza / kontynuacja / zaległość / luty przestępny), wpisowe, uprawnienia skarbnika, writeBack z mockiem arkusza, odrzucenie |
